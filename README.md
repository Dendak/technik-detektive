# Technik-Detektive

Interaktive Übungsseite für Digitale Grundbildung (2. Klasse): Echt oder Fake?, Alarm-Training (gefälschte Virenwarnung verlassen), Detektiv-Fälle, Ticket-Check für gute Fehlermeldungen.

Online: https://dendak.github.io/technik-detektive/

Alle Meldungen sind nachgebaut, Telefonnummern und Adressen erfunden (.example). Es wird nichts gespeichert.
